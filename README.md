# CamAnchor

Mantém as configurações da sua webcam fixas no Windows durante lives e chamadas.

## Download

A versão mais recente está sempre em **[Releases](../../releases/latest)**.

Cada versão traz dois downloads:

- **CamAnchor** (app para Windows): funciona com Teams, WhatsApp, Discord e outros programas.
- **Plugin para OBS Studio**: para quem faz live pelo OBS.

## Suporte

Abra uma [issue](../../issues) descrevendo o problema e o modelo da sua webcam.
